# Дурак Помощник — Android-приложение

Android-приложение для помощи в карточной игре «Дурак онлайн». Отслеживает карты, считает вероятности и подсказывает оптимальные ходы.

## Возможности

- **Подсчёт карт** — отслеживание всех 36 карт (свои, на столе, в сбросе, неизвестные)
- **Подсказки ходов** — рекомендации для атаки, защиты и подкидывания
- **Анализ козырей** — сколько козырей осталось у противников
- **2-6 игроков** — поддержка любого количества игроков
- **AI-советы** (опционально) — интеграция с GigaChat или OpenAI API
- **Работает без интернета** — встроенная логика подсказок не требует API

## Установка APK

1. Скачайте файл `app-debug.apk` из папки `durak-helper/app/build/outputs/apk/debug/`
2. Перенесите APK на телефон
3. В настройках Android разрешите установку из неизвестных источников
4. Откройте APK и установите

## Сборка из исходников

### Требования

- **JDK 17** (OpenJDK или Oracle JDK)
- **Android SDK** (API 34, Build Tools 34.0.0)

### Команды сборки

```bash
cd durak-helper

# Linux/macOS
./gradlew assembleDebug

# Windows
gradlew.bat assembleDebug
```

APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

## Как пользоваться

### Начало игры

1. Откройте приложение
2. Выберите количество игроков (2-6)
3. Выберите козырную масть
4. Нажмите «Начать игру»

### Во время игры

1. **Режим «Мои карты»** — нажимайте на карты в сетке, чтобы отметить свои карты (зелёный цвет)
2. **Режим «На стол»** — отмечайте карты, которые сыграны на стол (оранжевый цвет)
3. **«Бито»** — когда раунд завершён, карты со стола уходят в сброс (серый цвет)
4. **«Забрали»** — если кто-то забрал карты со стола
5. Подсказки обновляются автоматически

### Цвета карт в сетке

| Цвет       | Значение              |
|------------|-----------------------|
| Голубой    | Неизвестная карта      |
| Зелёный    | Моя карта             |
| Оранжевый  | На столе              |
| Серый      | В сбросе (бито)       |

### AI-советы (опционально)

1. Откройте «Настройки AI» на главном экране
2. Выберите тип API (GigaChat или OpenAI)
3. Введите API-ключ:
   - **GigaChat**: Base64 от `CLIENT_ID:CLIENT_SECRET`
   - **OpenAI**: ключ вида `sk-...`
4. Сохраните настройки
5. В игре нажимайте «Спросить AI» для получения совета

## Технические детали

- **Язык:** Kotlin
- **Min SDK:** 24 (Android 7.0)
- **Target SDK:** 34 (Android 14)
- **Библиотеки:** AndroidX, Material Components, OkHttp (для AI)
- **Колода:** 36 карт (6, 7, 8, 9, 10, В, Д, К, Т × 4 масти)
