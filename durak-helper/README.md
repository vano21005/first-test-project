# Дурак Помощник — Оверлей для игры

Android-приложение, которое работает **поверх игры «Дурак онлайн»** и в реальном времени распознаёт карты с экрана, считает их и подсказывает ходы.

## Возможности

- **Работает поверх игры** — плавающее окно с подсказками
- **Захват экрана** — скриншоты через MediaProjection API
- **Распознавание карт** — Google ML Kit OCR (офлайн, не грузит телефон)
- **Подсчёт карт** — отслеживание всех 36 карт (свои, на столе, в сбросе, у противников)
- **Подсказки ходов** — рекомендации для атаки и защиты
- **Анализ козырей** — сколько козырей осталось у противников
- **2-6 игроков** — поддержка любого количества
- **Авто-сканирование** — каждые 5 секунд (или вручную по кнопке)
- **AI-советы** (опционально) — GigaChat или OpenAI API

## Установка

1. Скачайте APK из релизов
2. Разрешите установку из неизвестных источников
3. Установите APK

## Как пользоваться

### Запуск

1. Откройте «Дурак Помощник»
2. Выберите козырь и количество игроков
3. Нажмите **«Запустить помощник»**
4. Разрешите показ поверх приложений
5. Разрешите захват экрана
6. Откройте игру «Дурак онлайн»

### Во время игры

- **♠** — свернуть/развернуть панель помощника
- **Скан** — сделать скриншот и распознать карты
- **Авто** — включить автоматическое сканирование (каждые 5 сек)
- **Бито** — когда раунд завершён (карты в сброс)
- **Забрали** — кто-то забрал карты со стола
- **Сброс** — начать новую игру

### Что показывает

- **Мои карты** — распознанные карты в нижней части экрана
- **Стол** — карты в центре экрана
- **Статистика** — бито, неизвестные, козыри
- **Подсказки** — советы по стратегии

## Сборка из исходников

```bash
# Требования: JDK 17, Android SDK 34
cd durak-helper
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

## Структура проекта

```text
durak-helper/app/src/main/java/com/durakhelper/
├── Card.kt            # Модель карты (масть, номинал, 36 карт)
├── GameState.kt       # Состояние игры, подсчёт, подсказки
├── CardRecognizer.kt  # ML Kit OCR + анализ цвета
├── OverlayService.kt  # Плавающее окно + захват экрана
├── AiHelper.kt        # GigaChat / OpenAI интеграция
├── MainActivity.kt    # Настройка и запуск
└── SettingsActivity.kt # API-ключ
```

## Технические детали

- **Язык:** Kotlin
- **Min SDK:** 24 (Android 7.0)
- **Target SDK:** 34
- **OCR:** Google ML Kit Text Recognition (офлайн)
- **Захват экрана:** MediaProjection API
- **Оверлей:** WindowManager TYPE_APPLICATION_OVERLAY
- **AI (опционально):** OkHttp + GigaChat / OpenAI API

## Разрешения

| Разрешение | Зачем |
|---|---|
| `SYSTEM_ALERT_WINDOW` | Показ поверх других приложений |
| `FOREGROUND_SERVICE_MEDIA_PROJECTION` | Захват экрана |
| `INTERNET` | AI-советы (опционально) |
