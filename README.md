# 💡 Генератор идей — Telegram-бот с GigaChat

Telegram-бот, который генерирует персонализированные идеи на основе ваших интересов с помощью **GigaChat API** (модель GigaChat-2-Lite).

## Возможности

| Команда   | Описание                                                       |
|-----------|----------------------------------------------------------------|
| `/start`  | Приветствие и инструкция                                       |
| `/survey` | Опрос по интересам: хобби, работа, задачи, любимые темы        |
| `/ideas`  | Генерация 5 персонализированных идей через GigaChat            |
| `/reset`  | Сброс контекста пользователя                                   |

## Установка и запуск (Windows 10)

### 1. Установите Python

1. Перейдите на [python.org/downloads](https://www.python.org/downloads/).
2. Скачайте Python **3.10** или новее.
3. При установке **обязательно** поставьте галочку **«Add Python to PATH»**.
4. Проверьте установку — откройте **Командную строку** (`Win + R` → `cmd`) и выполните:
   ```bash
   python --version
   ```
   Должна отобразиться версия Python (например, `Python 3.12.x`).

### 2. Получите токен Telegram-бота

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Введите имя бота (отображаемое имя) и username (должен заканчиваться на `bot`).
4. BotFather пришлёт **токен** вида `123456789:ABCdefGhIjKlMnOpQrStUvWxYz`. Скопируйте его.

### 3. Скачайте проект

Скачайте ZIP-архив с GitHub или клонируйте репозиторий:

```bash
git clone https://github.com/vano21005/first-test-project.git
cd first-test-project
```

### 4. Создайте файл `.env`

В корне проекта создайте файл `.env` (без расширения) и вставьте:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
GIGACHAT_CREDENTIALS=ваш_client_id:ваш_client_secret
GIGACHAT_SCOPE=GIGACHAT_API_PERS
```

> **Замените** `ваш_токен_от_BotFather` на токен из шага 2.
> **Замените** `ваш_client_id:ваш_client_secret` на ваши данные от GigaChat.
>
> Пример для GigaChat credentials: `019ca4ee-571d-73a3-xxxx:f87c8736-58b1-xxxx`

#### Как получить данные GigaChat

1. Зарегистрируйтесь на [developers.sber.ru](https://developers.sber.ru/).
2. Создайте проект и получите **Client ID** и **Client Secret**.
3. Формат для `.env`: `CLIENT_ID:CLIENT_SECRET` (через двоеточие).

### 5. Установите зависимости

В командной строке (в папке проекта) выполните:

```bash
pip install -r requirements.txt
```

### 6. Запустите бота

```bash
python bot.py
```

Бот запустится и начнёт принимать сообщения в Telegram. Для остановки нажмите `Ctrl + C`.

## Использование

1. Откройте бота в Telegram (найдите его по username, который указали в BotFather).
2. Отправьте `/start` — бот поприветствует вас.
3. Отправьте `/survey` — ответьте на 4 вопроса о ваших интересах.
4. Отправьте `/ideas` — бот сгенерирует 5 персонализированных идей.
5. Отправьте `/reset`, чтобы очистить контекст и пройти опрос заново.

## Технические детали

- **Python 3.10+**
- **aiogram 3.x** — асинхронный фреймворк для Telegram Bot API
- **gigachat** — официальный SDK от Сбера для GigaChat API
- **python-dotenv** — загрузка переменных окружения из `.env`
- **Модель:** GigaChat-2-Lite (быстрая, бесплатные токены ~900k)
- **Потоковый режим** генерации (streaming)
- **FSM (машина состояний)** для пошагового опроса
- История диалога: до 10 последних сообщений
